# 中国政府统计数据「统计局之外」替代/补充数据源侦察报告

> 侦察对象：`stats-collector` 项目（现仅从国家统计局官网逐级发现省/地级市统计局站点，抓取年度统计公报，规则 + LLM 抽取入 SQLite）
> 试点范围：福建省 + 9 个设区市；分析对象以**地级市（如泉州市）**为主
> 侦察性质：**只读侦察**。未修改 `stats-collector` 下任何既有代码或文档，未安装依赖，未注册账号，未下载大数据集。
> 本文件为本次侦察的唯一新建产物。

## 1. 调研方法与实测环境说明

### 1.1 实测环境（本机事实）

| 项 | 值 |
|---|---|
| 操作系统 / Shell | Windows + PowerShell 7（`pwsh`） |
| 出口 IP | `123.244.186.191`（中国境内，中国电信辽宁）；部分请求经 IPv6 `240e:40e:1f02:...` |

### 1.2 关键环境坑（影响所有后续采集，务必记录）

1. **PowerShell `Invoke-WebRequest` 不可作为可达性判据。**
   实测 `Invoke-WebRequest -Uri "https://data.stats.gov.cn/easyquery.htm?cn=E0103"` 返回
   `远程服务器返回错误: (403) 已禁止`，而同一 URL 用 `curl.exe` 也是 403 —— 但
   `https://www.stats.gov.cn/` 用 `curl.exe` 是 **200**、用 `Invoke-WebRequest` 是 403。
   即 PowerShell 的 TLS 指纹会被部分政府站 WAF 拦截，**不等于站点不可达**。本报告所有状态码均以 `curl.exe -4` 为准。

2. **`data.stats.gov.cn/easyquery.htm` 已被 WAF 按 URL 封禁（这是本项目最大的既有误判）。**
   实测响应体明文：
   ```
   <center>Client IP: 240e:40e:1f02:1e82:dd62:6af7:cd40:a4ad</center>
   <center>eventID: 1249-1789380175.865-s2czt reason:UrlACL</center>
   ```
   换 `cn=E0103 / C01 / E0105 / A0201`、补 `Referer`、补 `X-Requested-With`、补完整浏览器头、强制 IPv4 —— **全部 403**。
   ⇒ **旧 easyquery 接口在本机网络下已不可用，不要再投入。** 但**新版接口可用**（见 §2 与 §3.1，这是本次最高价值产出）。

3. `raw.githubusercontent.com` → `getaddrinfo ENOENT`（DNS 不可达）；`https://www.data.gov.cn/` → `000`。

### 1.3 实测方法

- 可达性：`curl.exe -4 -s -o NUL -w "%{http_code} %{size_download} %{time_total}" --max-time 25 -A "<Chrome/131 UA>" "<URL>"`
- 正文：`curl.exe -4 -s --max-time 25 -A "<同上 UA>" "<URL>"`；政府站多为 `gb2312`，PowerShell 下中文乱码属正常，实际解析时按编码显式解码
- 接口：GET / POST 分别实测，记录状态码 + 响应字节数 + 响应体片段
- **凡未实测者一律标注「未核实」；凡实测失败者如实写明失败原因，不做成功推断。**

## 4. 可以用于交叉验证的源组合（抗「数据美化」）

对抗地方政府数据美化的关键，是找到**不同部门、不同采集口径**的第二数据点。以下组合均已实测可达：

| 待验证指标 | 数据点 1（统计局口径） | 数据点 2（**独立口径**） | 为什么能互相印证 |
|---|---|---|---|
| **泉州市进出口 / 外贸** | 泉州统计年鉴「对外经贸发展情况」表（`zktjnj.../0112.htm`）与年度统计公报 | ★ **厦门海关「本关统计」分市月度进出口表**（实测 200，含泉州） | 海关是**货物实际通关**口径，与统计局会商口径不同源；差异可暴露口径调整或注水 |
| **福建省 GDP / 财政收支** | 泉州/福建统计年鉴、统计局新版 API 分省年度（1992 起） | **CELMA 平台 `zb=1201`（GDP）、`1101`（一般公共预算收入）** | 财政部债务中心口径，独立编制；⚠️ 但 CELMA `1204` 进出口序列实测异常，须先对账 |
| **福建省政府债务规模** | 省级预决算报告（**未核实**具体入口） | **CELMA `060101`/`060102`（一般/专项债务余额，省级，2015–2025）** | 债务口径唯一权威增量源，可与预决算披露值互校 |
| **泉州工业/经济活动强度** | 泉州年鉴工业章、规上工业增加值 | ★ **VIIRS 夜间灯光（eogdata，实测 200）** | 灯光是**卫星观测**，完全不受地方政府影响，是最强抗美化代理变量 |
| **泉州环境质量** | 年鉴环境章 / 统计公报 | **生态环境部空气质实时发布（air.cnemc.cn:18007，实测 200）** | 监测总站口径，独立上报体系 |

## 5. 按性价比排序的落地建议 Top 5

### ① 接入「泉州统计年鉴 2015–2025」在线 HTML —— **补 A 类全部缺口**
- **补什么**：2024 及更早的 GDP、三次产业增加值、财政收支、进出口、城镇新增就业、常住人口 —— A 类最痛的问题**一次性根治**

  `https://tjj.quanzhou.gov.cn/tsys/UpLoadFiles/43sjfb/129ndsj/qztjnj<年>/contents-cn.htm` 循环 2016–2025（10 年，实测全部 200），解析 `./cn/html/NNNN.htm` 逐表抓取（HTML 表，编码 `gb2312`/`utf-8` 需探测）。优先抓 `0102`（国民经济主要年份主要指标）、`0107`（地区生产总值）、`0108`（财政收入）、`0112`（对外经贸）、`0114`（人民生活）。**2015 年**为 PDF（24 MB），单独走 PDF 表格抽取
- **预计工作量**：**1–1.5 人日**（URL 确定性高，无需处理详情页跳转；复用既有「规则+LLM 抽取」管线）；2015 PDF 额外 +0.5–1 人日做表格识别

- **预计工作量**：**1–2 人日**（纯 HTML，比泉州年鉴更简单）

### ③ 接入 CELMA 政府债务公开 API —— **唯一能真正突破 C 类「制度性不公布」的免费 JSON 源**
- **补什么**：政府债务**一般债/专项债分项**（余额、限额、债券余额、发行额），省级、年度 2015–2025 + 月度 2018-01 起

- **注意**：**只到省级**，泉州拿不到；`12xx` 社会经济序列须先对账
- **预计工作量**：**0.5–1 人日**（一个 GET 循环）
