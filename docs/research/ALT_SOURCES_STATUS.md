### 接入过程中发现的**硬约束**(务必遵守,否则必然失败)

| 约束 | 现象 | 处理 |
|---|---|---|
| CELMA 需**浏览器 UA** | 用 `requests` 默认 UA 直接 **418**;换浏览器 UA 得 200 | `app/fetch/celma.py` 内置 UA + Referer |
| CELMA 证书链异常 | `verify=True` 失败 | `verify=False` |
| 政府站多为 GB2312 | 裸 `decode("utf-8")` 得乱码、正则全不命中 | 一律走 `decode_html()` |
| 正文数字常被标签包裹 | `预计执行数</span>2661.16</span>亿元`,把**原始 HTML** 喂文本正则会全不命中 | 必须先 `extract_text()` |

## 2. 本轮复测**失败**的源(与前报告结论冲突,以此为准)

### 厦门海关「本关统计」——现已 412

`ALT_SOURCES.md` §3.3 记录该源 200/28529B 且正文含「泉州」20 处,
**判定为"唯一能到地级市的独立口径源"**。本轮复测:

| 请求 | 结果 |
|---|---|
| `http://xiamen.customs.gov.cn/` | **412** / 2499B |
| `.../zwgk/zfxxgk22/3017978/3018709/491081/index.html` | **412** / 2716B |
| 加完整浏览器头(UA + Accept + Accept-Language + Referer) | **仍 412** |
| 正文「泉州」出现次数 | **0** |

412 是**加速乐(JS 挑战)**的典型响应。⇒ 纯 HTTP 客户端不可得,
**必须真实 JS 环境(Playwright 等)**,属 L 成本,与 `customs.gov.cn` 主站同一障碍。

**处置**:`app/fetch/customs.py` **未实现**。地市级外贸的独立口径暂缺;
在补齐前,进出口数据仍只有统计局单一来源(不可交叉验证)。
