# 证据:数据缺口的真实归因(2026-09-08)

> 目的:把「拿到的数据不全」从主观感受变成可核验的量化证据,判定缺口究竟来自
> ①统计局未披露 ②我们没采集 ③采集到了但抽取失败,并据此给改造排序。
> 方法:真实库 `data/stats.db` 全量统计 + 决策树 `tree_audit` 复跑 + 10 个站点栏目页实测。

## 1. 结论摘要(三条反直觉发现)

**① 主因不是「统计局没披露」,是「站点适配不完整」。**
宁德市被成功采到 **26 个年度公报页(2000-2025)**、抽出 **21 个年度的 GDP** —— 这证明现有
管线**完全具备多年回溯能力**。而泉州 **0 个公报页**、福建省仅 2 页、厦门/龙岩/莆田各 1 页。
同一套代码在两个站点上一个采到 26 年、一个采到 1 年,差异**只来自站点栏目定位与分页遍历是否命中**。

**② 泉州是唯一的「旁路城市」,它的时序缺口是自己造的。**
泉州全部数据来自手工单期注册表 `config/quanzhou_sources.yaml`(6 个源,period 全是 2025/2026),
**从未走过 `orchestrator` 的公报发现路径**。而泉州统计局公报栏目实测可回溯到 **2007 年**:
`/tjzl/tjgb/`(2022-2025)、`index_1.htm`(2019-2022)、`index_2.htm`(2015-2019)、
`index_3.htm`(2010-2015)、`index_4.htm`(2007-2010)。**19 年数据一直公开着,我们没有去取。**

**③ 决策树里 7 个「无法裁决(na)」节点,全部是时序深度不足导致的。**
它们需要的都是「相邻两年」的同一口径数据;而入库的多数地区只有单年值。
**没有一个是「统计局不公布」造成的。**

## 6. 代码级根因

| 位置 | 问题 |
|---|---|
| `app/orchestrator.py:61-75` `_bulletin_candidates` | 非手工机构**只抓首页**再找公报链接;首页通常只挂最新一期 → 只有 1 个候选 |
| `app/orchestrator.py:41-58` `_listing_detail_links` | 下钻一层后**不遍历分页**,只取栏目第一页 |
| `app/orchestrator.py:26-35` `_find_bulletin_links` | 关键词命中即收,导致**「执法证公示」被当作 bulletin 入库**(福建省 1 页);栏目页自身也被当正文入库(福建省 `/xxgk/tjgb/`) |
| `app/fetch/search.py` + `bureaus.yaml`(莆田 was5) | 配置 `perpage=50` 但**无分页遍历** |
| `config/quanzhou_sources.yaml` | **手工单期清单**,无「按年回溯」概念 → 泉州时序恒为 1 年 |
| `app/fetch/client.py:41-53` `_get_raw` | 无 per-site TLS 容错(三明 SSL 失败)、无 Referer 能力(厦门 403)、无站点级重试策略 |
| 采集目标 | 无「年度区间」目标概念(如「采 2015-2025 全部年度公报」),`default_year` 仅作兜底标注 |

## 7. 对改造排序的输入

按「收益 / 成本」排序(用户已确认四轨全要、只用免费公开源、福建试点):

1. **时间深度(最高性价比)**:栏目页定位 + 分页遍历 + 年度区间目标。
   - 预期收益:泉州 1→19 年、福建省 1→26 年;直接解锁 7 个 na 节点中的 6 个时序类。
   - 成本:低。无需新数据源,复用现有 fetch/extract/store。
2. **抽取覆盖**:CPI / 常住人口 / 固投的地区覆盖补齐。
   - 预期收益:18 个指标中 4 个的覆盖从 3-5 地区提到 8-10 地区。
   - 成本:中(fallback 规则 + LLM 兜底)。
3. **异源接入**:仅针对制度性不公布项(收入中位数、支出法 GDP、债务分项、分行业税收)。
   - 成本:高。详见 `ALT_SOURCES.md`(调研中)。
4. **交叉验证框架**:让关键指标有第二个独立数据点。
   - 成本:中,但**依赖前三轨提供多源数据**。

**重要提醒**:第 1 轨不做,第 3、4 轨的收益会被严重稀释 —— 因为异源多数只能提供「最新一年」,
而当前瓶颈是**序列**;先用免费同源把序列补齐,再让异源做「同年同指标的第二数据点」,交叉验证才成立。
