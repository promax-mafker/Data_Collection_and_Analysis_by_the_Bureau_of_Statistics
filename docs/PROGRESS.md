### 4.1 独立代码审查与修复（2026-09）

由独立审查子代理对 pipeline 健壮性与架构做只读审查，结论：**分层架构良好、依赖单向无环、注入式设计便于 fake；逐页/逐机构两层异常隔离正确**。已采纳修复：

| 级别 | 问题 | 处置 |
|------|------|------|
| C1 | run 状态机漏洞：全量失败也报 success，partial 分支不可达 | ✅ `_final_status`：errors==0→success / values>0→partial / 否则 failed（有回归测试） |
| C2 | URL 已存在内容更新时页面陈旧、数值重复累积 | ✅ upsert_page 刷新内容 + `replace_page_values` 整页替换（有回归测试） |
| I1 | robots.txt 每请求重抓、无超时 | ✅ 按站点缓存 + requests 带超时读取 + fail-open（有测试） |
| I2 | 发现阶段无隔离，单点异常整次 failed | ✅ 国家→省/省→市发现包 try，异常回退白名单锚点/记日志 |
| I3 | `Bureau.id` 回填契约未实现 | ✅ upsert 后回填 `.id`，resolver 直接用 parent.id |
| I4 | RuleExtractor 硬编码，LLM 无法注入 | ✅ `run_pipeline(..., extractor=None)` 可注入任意 Extractor |
| I6 | 候选 0 条无告警 | ✅ 记「未找到公报候选」日志 |
| I7 | 日志无 traceback | ✅ 页面/机构/管线异常均附 `traceback.format_exc()` |
| I8 | 两套解码口径不一致 | ✅ 统一 `fetch.parser.decode_html`（UTF-8→GB18030→GBK） |
| I5 | analysis 结果无稳定顺序 | ✅ `query_data` 加 `ORDER BY id` |
| Minor M1-M13 | 详见 §5 技术债 | 已采纳 M1 抖动退避等，其余记录待二期 |

合理取舍（审查认可）：同步串行采集、公报链接仅限本机域名（莆田 was 兜底）、规则抽取局限 + `raw_text` 溯源、reference_year 取全局最新、robots fail-open、手工锚点 verified=True。

### 4.2 「零数据」缺口治理（2026-09，A/B/C/D 四策）

真实验证发现两类缺口并针对性治理（均有回归测试）：

| 策 | 机制 | 解决 |
|----|------|------|
| **A 列表页下钻** | 公报候选若是栏目列表页（含同域「…统计公报…」详情链接）→ 自动下钻一层取详情正文，列表页本身不入库 | 三明等「首页→栏目页」结构此前被当正文抓取 → 0 值；现多年公报自动入库 |
| **B fallback 补漏** | 指标可配第二档宽松模式；章节限定 0 命中时全文再跑一次（护栏：城镇/农村排除、跨行容忍） | 常住人口 / CPI / 固定资产投资从全空到多市有值 |
| **C 自洽校验** | 分析层领域恒等式：三次产业和 = GDP、结构占比合计 ≈ 100% → ✓ / ⚠ 显性标注 | 噪声值显性化（如 730876 型假值会被否决） |
| **D listing_urls** | `manual_bureaus` 支持直连栏目 URL（漳州/南平 cms 站）；配合下钻取详情 | 漳州（GDP 6154）、南平（GDP 2190）等 cms 站补全 |

效果：13 机构 9 市全齐、99 页 / 701 值 / 0 错误；报告覆盖 10 地区；9 地区数据自洽全 ✓；名义增速激活（多年度 2020-2025）。

### 4.3 查询层宽容匹配（2026-09，M4.2）

用户反馈「查询福建省莆田市 2025 年第一产业增加值无结果」。诊断：**数据在库（158.35 亿元）而查询层为精确匹配**——`region=?` 精确对不上「福建省莆田市」/「2025年」。新增宽容解析（`repository.query_lax`，均有回归测试）：

| 输入 | 解析规则 | 例子 |
|------|---------|------|
| 地区 | 剥上级前缀（以地区名结尾）→ 后缀补全 → 双向包含；未识别给候选清单 | 「福建省莆田市」→莆田市；「莆田」→莆田市 |
| 指标 | 别名表（GDP→地区生产总值）→ 前缀补全 → 包含；歧义明确警告不静默 | 「第一产业」→第一产业增加值；「增加值」→ 警告多候选 |
| 年份 | 提取 4 位年份 | 「2025年」「2025 年度」→2025 |

关键取舍：**任一条件给出但解析失败时返回空行 + 明确警告**，绝不静默退回全量（避免用户误以为查询成功）。API 新增 `/api/filters` 供前端 datalist 候选提示（地区/指标/年份）；`/api/data` 与 `/api/export` 均走宽容解析。测试 36 → 47。

## 5. 已知限制 / 技术债

| 类别 | 说明 | 影响 |
|------|------|------|
| 网络抖动 | 个别地市某次运行可能漏检 | 重跑幂等累积即可补回 |
| 存量页规则 | fallback 等新规则仅对新入库页生效（内容哈希跳过旧页） | 需清库重跑或引入强制刷新才更新存量 |
| 规则局限 | 个别公报排版极端（如三明 2025 GDP 段）仍可能漏抽 | fallback 已覆盖多数；`raw_text` 溯源 |
| 港澳台口径 | 公报注脚（金门/马祖等口径差异）未建模 | 数据含注脚说明，分析时注意 |
| 莆田 PDF | 若为扫描版 PDF 无法提取文字 | 需 OCR（未引入） |
| token 安全 | GitHub MCP token 明文在 `.mcp.json`（已 gitignore） | 建议定期轮换 |
